# Slides · Monthly Review · V4 Oliveira & Co

Template for the **monthly review deck** that each unit ships internally and to its team. Mirrors the BI dashboard's visual language but at slide density (big type, brand-true layouts).

## Stack
- `deck-stage.js` web component (scaling, keyboard nav, print-to-PDF, slide rail)
- Static HTML `<section>` per slide — fully editable inline
- Design tokens from `../colors_and_type.css`
- Brand display sizes from V4 brand book (H1=72, H2=60)

## Slides included
01. Capa
02. Divisor · Resumo do mês
03. Hero number · Faturamento
04. KPI overview (4-up)
05. Trend chart · 12 meses
06. Divisor · Carteira
07. Destaques do mês
08. Em crise · plano de ação
09. Divisor · Método V4
10. Distribuição por pilar
11. Squad performance
12. Próximos passos
13. Closing · brand statement

Speaker notes are **not** included by default per design-system rules — add them when you customize for a specific month.
